# Packet Tweaker
This library provides an easy to use/access PacketContext, which can be use to store and retrieve data/objects within packet serialization and outside of it.

[For 26.1+, you should use PacketContext api provided within Fabric API instead!](https://maven.fabricmc.net/docs/fabric-api-0.143.11+26.1/net/fabricmc/fabric/api/networking/v1/context/PacketContext.html)
